Sales Analysis Dashboard 
Overview
The Sales Analysis Dashboard is an interactive report created in Microsoft Power BI Desktop using the Olist Brazilian E-Commerce Public Dataset. It organizes e-commerce information into three report pages to help users explore sales performance, geographic patterns, payment methods, and customer reviews.
Report Pages
1. Sales Overview
Summarizes overall sales performance using the key metrics and visuals available in the report.
2. Geographic Analysis
Helps users explore geographic patterns and compare sales across locations represented in the dataset.
3. Payments and Reviews
Presents payment-method information and customer review data to support further exploration of order payments and customer feedback.
Tools and Technologies
- Power BI Desktop — report creation and interactive visualizations
- Power Query — data import and transformation, where used
- DAX — measures and calculations, where used
- Olist Brazilian E-Commerce Public Dataset — project dataset

How to Open the Report
1. Download or clone the project folder.
2. Open PR_3.pbix in Microsoft Power BI Desktop.
3. If prompted, review the data-source settings and update any file paths or permissions.
4. Use the report tabs to navigate between Sales Overview, Geographic Analysis, and Payments and Reviews.
5. Use available slicers, filters, and visual interactions to explore the report.
Notes
